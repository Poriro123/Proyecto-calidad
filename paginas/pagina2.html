Fundamentos de la Calidad del Software

La calidad del software es la capacidad de un producto para cumplir con los requisitos del usuario y los objetivos del negocio. No se trata solo de que un sistema “funcione”, sino de que lo haga de manera confiable, eficiente, segura y fácil de mantener.

Conceptos clave de calidad

  • Confiabilidad: que el software funcione correctamente bajo distintas condiciones.
  • Usabilidad: facilidad de uso e interacción para el usuario.
  • Mantenibilidad: capacidad de actualizar, corregir y mejorar el sistema sin grandes costos.
  • Eficiencia: buen rendimiento con el uso óptimo de recursos.
  • Portabilidad: posibilidad de utilizar el software en distintos entornos.

Métricas de calidad

Las métricas permiten medir y controlar la calidad. Ejemplos:

  • Número de defectos encontrados por fase.
  • Cobertura de pruebas (% de código probado).
  • Tiempo medio para resolver fallas.
  • Satisfacción del usuario final.

Estándares internacionales (ISO 9126 / ISO 25000)

  • ISO 9126: definía seis características principales de calidad (funcionalidad, fiabilidad, usabilidad, eficiencia, mantenibilidad y portabilidad).
  • ISO 25000 (SQuaRE): evolución de la ISO 9126, que establece un marco actualizado para evaluar la calidad del software y de su proceso de desarrollo.

Técnicas de Aseguramiento de la Calidad

El Aseguramiento de la Calidad (QA) busca prevenir errores y garantizar que el software cumpla los estándares definidos.

Pruebas de software

  • Tipos: funcionales (validan lo que el sistema debe hacer) y no funcionales (rendimiento, seguridad, usabilidad).
  • Niveles:
    • Unitarias (validan componentes pequeños).
    • Integración (verifican interacción entre módulos).
    • Sistema (evalúan el software completo).
    • Aceptación (realizadas por el cliente/usuario).
  • Técnicas:
    • Caja negra: se prueban entradas y salidas sin conocer el código.
    • Caja blanca: se analiza la lógica interna del código.
    • Exploratorias: pruebas dinámicas sin guiones predefinidos.

Herramientas de Calidad

Para apoyar la gestión de calidad se utilizan herramientas que facilitan el trabajo en equipo y la trazabilidad de los defectos:

  • Gestión de pruebas: permiten planificar, ejecutar y documentar pruebas (ej.: TestRail, Zephyr).
  • Seguimiento de defectos: registran, priorizan y gestionan errores reportados (ej.: Jira, Bugzilla).
  • Análisis de calidad: miden la calidad del código fuente y detectan vulnerabilidades (ej.: SonarQube).
